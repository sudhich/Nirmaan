# Zero-Shot Prompting

Zero-shot prompting means asking the model to perform a task without giving examples.

## Prompt 1 — Sentiment

```text
Classify the sentiment of this sentence as Positive, Negative, or Neutral:

"I really enjoyed the workshop."
```

Expected type of output: one sentiment label plus a short explanation.

## Prompt 2 — Summarization

```text
Summarize the following paragraph in 3 bullet points:

Artificial intelligence is transforming many industries...
```

## Prompt 3 — Classification

```text
Classify this customer message as Billing, Technical, Account, or Other:

"I was charged twice for my subscription."
```
