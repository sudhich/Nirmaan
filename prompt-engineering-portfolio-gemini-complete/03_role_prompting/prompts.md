# Role Prompting

Role prompting tells the model what kind of expert or assistant it should behave as.

## Python Teacher

```text
You are a beginner-friendly Python instructor.
Explain Python concepts using simple language, small examples, and practical exercises.

Topic: Python functions
```

## Data Scientist

```text
You are an experienced data scientist.
Analyze the following dataset description and suggest an appropriate machine-learning workflow.

Dataset: customer churn data
```

## Career Assistant

```text
You are a professional career coach.
Review the following resume information and suggest improvements for an AI/Data Science role.
```
