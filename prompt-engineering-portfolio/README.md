## Setup

Create a virtual environment:

```bash
python -m venv venv
```

Windows:

```bash
venv\Scripts\activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Set your API key:

Windows PowerShell:
```powershell
$env:OPENAI_API_KEY="your_api_key_here"
```

Run an application:

```bash
cd 06_resume_analyzer
python app.py
```

Then open:

`http://127.0.0.1:5000`

The same process can be used for the other Flask applications.
