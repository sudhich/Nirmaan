# Role Prompting

Role prompting gives the model a professional role and defines how it should behave.

## Example

```text
You are an experienced Python instructor.

Explain Python to a beginner who has never written code before.

Requirements:
- Use simple language.
- Give real-world examples.
- Include short code examples.
- Explain step by step.
- Avoid unnecessary technical jargon.
```

The role, audience, and requirements make the expected response clearer.
