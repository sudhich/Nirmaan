# Zero-Shot Examples

## Example 1 — Sentiment

Input:
> The product is excellent.

Output:
> Positive

## Example 2 — Topic Classification

Prompt:

```text
Classify this sentence into Technology, Sports, Business, or Education:

"Python is widely used in machine learning."

Return only the category.
```

Expected:
`Technology`

## Example 3 — Summarization

```text
Summarize the following paragraph in one sentence:

Artificial intelligence is being used across healthcare, finance,
education, manufacturing, and customer service.
```
