# Prompt Optimization — After

## Improved Prompt

```text
You are an AI educator creating educational LinkedIn content.

Write a LinkedIn post explaining how Generative AI is changing software development.

Audience:
Beginners and working professionals.

Requirements:
- Start with an attention-grabbing opening.
- Explain the concept simply.
- Include 3 practical examples.
- Include one important limitation.
- End with a question for readers.
- Use short paragraphs.
- Maximum 180 words.
- Add 5 relevant hashtags.

Return only the final LinkedIn post.
```

## Improvements

The optimized prompt adds role, audience, task, constraints, structure, length, and output requirements.
